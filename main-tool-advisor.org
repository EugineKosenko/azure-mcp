#+title: Інструмент ~advisor~

Рекомендації =Azure Advisor= підписки (усі категорії: ~Cost~, ~HighAvailability~, ~Security~,
~Performance~, ~OperationalExcellence~) — звичайний =arm= ~GET~ (~Microsoft.Advisor/recommendations~,
~api-version=2025-01-01~, перевірено живим викликом 2026-09-25), тим самим токеном ~az~, що й решта
інструментів; не =Cost Management= і без окремого кешу. Замінює нестабільний офіційний =npx
@azure/mcp= (падав ~CONNECT_TIMEOUT~ / ~CONNECTION_CLOSED~ в іншому проєкті) прямим зверненням. Опис для
~tools/list~ і диспетчеризація — в [[file:main-tools.org][~main-tools.org~]].

* Таблиця

=Api= не підтримує звуження шляху групою ресурсів (перевірено живим викликом: ~404~) — лише підписку, тож
~group~ фільтруємо після завантаження, за тим самим принципом, що ~name~ у [[file:main-tool-disks.org][~disks~]]. Рекомендація без
конкретного ресурсу (напр. «купіть зарезервований інстанс») має ~resourceMetadata/resourceId~ рівнем
підписки — без сегмента ~resourceGroups~, тоді показуємо «підписка» замість самого ідентифікатора.
Економію показано, лише коли вона є в ~extendedProperties~ (не всі категорії й типи рекомендацій її
несуть).

#+end_src

#+begin_src rust :noweb-ref Визначення
  fn resource(id: &str) -> String {
      if tools::part(id, "resourceGroups") == "-" { "підписка".to_string() } else { tools::last(id).to_string() }
  }

  fn economy(item: &serde_json::Value) -> String {
      let amount = tools::text(item, "/properties/extendedProperties/annualSavingsAmount");
      let currency = tools::text(item, "/properties/extendedProperties/savingsCurrency");

      if amount == "-" { "-".to_string() } else { format!("{} {}/рік", amount, currency) }
  }

  fn line(item: &serde_json::Value) -> String {
      let id = tools::text(item, "/properties/resourceMetadata/resourceId");

      format!(
          "{}  {}  {}  {}  {}  {}",
          tools::part(id, "resourceGroups"),
          tools::text(item, "/properties/impact"),
          tools::text(item, "/properties/category"),
          resource(id),
          economy(item),
          tools::text(item, "/properties/shortDescription/problem"),
      )
  }

  fn table(items: &[serde_json::Value], category: Option<&str>, group: Option<&str>) -> String {
      let lines: Vec<String> = tools::sorted(items)
          .into_iter()
          .filter(|item| category.is_none_or(|category| tools::same(tools::text(item, "/properties/category"), category)))
          .filter(|item| {
              group.is_none_or(|group| {
                  tools::same(tools::part(tools::text(item, "/properties/resourceMetadata/resourceId"), "resourceGroups"), group)
              })
          })
          .map(line)
          .collect();

      if lines.is_empty() { "Рекомендацій не знайдено.".to_string() } else { lines.join("\n") }
  }
#+end_src

* Перевірки

Зразок — скорочена реальна відповідь =api= (2026-09-25, дані замінено на вигадані): рекомендація для
конкретної =vm= й рекомендація на рівні підписки (без сегмента групи в ~resourceId~).
