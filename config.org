#+title: Залежності

Компонент проєкту називається ~am-mcp~ (код проєкту ~am~ і назва компонента ~mcp~), а крейт —
~azure-mcp~. Сервер не використовує жодного стороннього крейта для самого протоколу =mcp=: =json-rpc=
реалізовано напряму, як у ~fm-mcp~ і ~org-tmetric-mcp~, див. [[file:main.org][~main.org~]].

* =Cargo=

#+begin_src toml :noweb yes :mkdirp yes :tangle Cargo.toml
  [package]
  name = "azure-mcp"
  version = "0.1.0"
  edition = "2021"

  [dependencies]
  <<Залежності>>
#+end_src

* =dotenvy=

Читає ~.env~ лише під час локальної розробки (~cargo run~); у продуктивному режимі змінні передає сама
реєстрація сервера, див. [[file:env.org][~env.org~]]. Крейт ~dotenv~ застарілий, тому використано ~dotenvy~.

#+begin_src toml :noweb-ref Залежності
  dotenvy = "*"
#+end_src

* =serde_json=

#+begin_src toml :noweb-ref Залежності
  serde_json = "*"
#+end_src

* =tokio=

Можливості: асинхронне читання й запис стандартного вводу-виводу (~io-std~, ~io-util~) — так сервер
спілкується з клієнтом =mcp=; ~process~ — виклик ~az~ по токен, див. [[file:main-client.org][~main-client.org~]]; ~time~ — паузи
між повторами запиту при ~429~.

#+begin_src toml :noweb-ref Залежності
  tokio = { version = "*", features = ["macros", "rt-multi-thread", "io-std", "io-util", "process", "time"] }
#+end_src
