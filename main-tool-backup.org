#+title: Інструмент ~backup~

Повертає стан =Azure Backup=: сховища (~Microsoft.RecoveryServices/vaults~), їхні політики й захищені
елементи (що саме захищено, з якою політикою, коли був останній бекап і скільки точок відновлення).  Лише
читання: жодних операцій відновлення чи зміни захисту, вмісту точок відновлення не читаємо. Опис для
~tools/list~ і диспетчеризація — в [[file:main-tools.org][~main-tools.org~]].

Виклики (~api-version=2023-04-01~, підтверджено живим викликом), усі ~GET~, достатньо ролі ~Reader~:

- сховища області: ~{область}/providers/Microsoft.RecoveryServices/vaults~ (~api-version=2024-04-01~);
- налаштування безпеки сховища: ~GET {сховище}~ (та сама версія; у переліку їх немає);
- тип зберігання: ~{сховище}/backupstorageconfig/vaultstorageconfig~ (~storageModelType~);
- політики: ~{сховище}/backupPolicies~;
- захищені елементи: ~{сховище}/backupProtectedItems~;
- точки відновлення елемента: ~{елемент}/recoveryPoints~ — лише кількість.

Розмір збережених даних і вартість на елемент цей інструмент не показує: =arm= не віддає їх окремим
полем, а вартість виводиться з =Cost Management= (інструмент [[file:main-tool-costs.org][~costs~]], розбивка за ресурсом).

* Сховище

Рядок сховища: група, регіон, SKU, тип зберігання й кількість захищених елементів, а далі (у кінці рядка)
налаштування безпеки, які вирішують, чи вдасться видалити дані бекапу: ~immutable~ — незмінність сховища
(~Disabled~ / ~Unlocked~ / ~Locked~; увімкнена незмінність (~Unlocked~ чи ~Locked~) не дає видалити точки
відновлення й зупинити захист із видаленням даних, помилка ~UserErrorDeleteBackupItemOnImmutableItem~,
підтверджено на практиці з ~Unlocked~; ~unreported~ — =Azure= блок налаштувань не повернув, стан
невідомий); ~softdelete~ — стан м'якого видалення, кількість діб зберігання видалених даних і ~enhanced~
(~Enabled~ — «завжди увімкнене», вимкнути не можна); ~mua~ — багатокористувацька авторизація
(~multiUserAuthorization~); ~crr~ — відновлення між регіонами (~crossRegionRestore~). Усе це поля
~properties~ самого сховища (~securitySettings~, ~redundancySettings~); перелік сховищ області їх не
повертає (лише ім'я, регіон, SKU), тож для кожного сховища додатково читається саме сховище (~GET
{сховище}~). ~storageModelType~ =Azure= повертає словом (~LocallyRedundant~, ~GeoRedundant~,
~ZoneRedundant~), у таблицю потрапляє звична абревіатура (~LRS~, ~GRS~, ~ZRS~); невідоме значення
показуємо як є.

  fn redundancy(config: &serde_json::Value) -> &str {
      match tools::text(config, "/properties/storageModelType") {
          "LocallyRedundant" => "LRS",
          "GeoRedundant" => "GRS",
          "ZoneRedundant" => "ZRS",
          other => other,
      }
  }

  fn vault(item: &serde_json::Value, full: &serde_json::Value, config: &serde_json::Value, count: usize) -> String {
      format!(
          "{}  {}  {}  {}  storage={}  items={}  immutable={}  softdelete={}({}d,enhanced={})  mua={}  crr={}",
          tools::text(item, "/name"),
          tools::part(tools::text(item, "/id"), "resourceGroups").to_lowercase(),
          tools::text(item, "/location"),
          tools::text(item, "/sku/name"),
          redundancy(config),
          count,
          full.pointer("/properties/securitySettings/immutabilitySettings/state").and_then(|state| state.as_str()).unwrap_or("unreported"),
          tools::text(full, "/properties/securitySettings/softDeleteSettings/softDeleteState"),
          tools::shown(full, "/properties/securitySettings/softDeleteSettings/softDeleteRetentionPeriodInDays"),
          tools::text(full, "/properties/securitySettings/softDeleteSettings/enhancedSecurityState"),
          tools::text(full, "/properties/securitySettings/multiUserAuthorization"),
          tools::text(full, "/properties/redundancySettings/crossRegionRestore"),
      )
  }

* Політика

Політика описує розклад і зберігання. Розклад: частота (~Daily~ / ~Weekly~ / ~Hourly~) і час запуску
(лише ~гг:хх~, у часовій зоні політики). Стара форма (~SimpleSchedulePolicy~) тримає частоту й час на
верхньому рівні, нова (~SimpleSchedulePolicyV2~) — усередині ~dailySchedule~, ~weeklySchedule~ чи
~hourlySchedule~.  Зберігання: для кожного рівня (~daily~, ~weekly~, ~monthly~, ~yearly~) кількість і
одиниця (~d~ дні, ~w~ тижні, ~m~ місяці, ~y~ роки); проста політика має один ~retentionDuration~
(~keep=~). ~instant~ — скільки днів зберігаються миттєві ~snapshot~-и (~instantRpRetentionRangeInDays~),
~-~, коли не задано. ~items~ — скільки захищених елементів сховища використовують політику: рахуємо самі
за ~policyName~ елементів, бо власне поле політики (~protectedItemsCount~) у живих відповідях показувало
~0~ для політик, якими користуються елементи.

#+begin_src rust :noweb-ref Визначення
  fn times(schedule: &serde_json::Value) -> String {
      let found: Vec<String> = ["/scheduleRunTimes", "/dailySchedule/scheduleRunTimes", "/weeklySchedule/scheduleRunTimes"]
          .iter()
          .filter_map(|pointer| schedule.pointer(pointer)?.as_array())
          .flatten()
          .map(|time| time.as_str().unwrap().chars().skip(11).take(5).collect())
          .collect();

      if found.is_empty() { "-".to_string() } else { found.join(",") }
  }

  fn schedule(policy: &serde_json::Value) -> String {
      let base = policy.pointer("/properties/schedulePolicy").unwrap_or(&serde_json::Value::Null);
      let hourly = base.pointer("/hourlySchedule/interval").map(|hours| format!("every {}h", hours));

      format!("{} {}", tools::text(base, "/scheduleRunFrequency"), hourly.unwrap_or_else(|| times(base)))
  }

  fn duration(policy: &serde_json::Value, pointer: &str) -> Option<String> {
      let count = policy.pointer(&format!("{}/count", pointer))?;
      let unit = tools::text(policy, &format!("{}/durationType", pointer)).chars().next()?.to_ascii_lowercase();

      Some(format!("{}{}", count, unit))
  }

  fn keep(policy: &serde_json::Value) -> String {
      let base = "/properties/retentionPolicy";
      let levels: Vec<String> = [("daily", "dailySchedule"), ("weekly", "weeklySchedule"), ("monthly", "monthlySchedule"), ("yearly", "yearlySchedule")]
          .iter()
          .filter_map(|(label, key)| Some(format!("{}={}", label, duration(policy, &format!("{}/{}/retentionDuration", base, key))?)))
          .chain(duration(policy, &format!("{}/retentionDuration", base)).map(|value| format!("keep={}", value)))
          .collect();

      if levels.is_empty() { "-".to_string() } else { levels.join(" ") }
  }

  fn policy(item: &serde_json::Value, count: usize) -> String {
      format!(
          "  policy {}  {}  {}  keep: {}  instant={}  items={}",
          tools::text(item, "/name"),
          tools::text(item, "/properties/backupManagementType"),
          schedule(item),
          keep(item),
          tools::shown(item, "/properties/instantRpRetentionRangeInDays"),
          count,
      )
  }

* Захищений елемент

Рядок елемента: ім'я (~friendlyName~, для VM — її ім'я), політика, стан захисту, здоров'я, результат і
час останнього бекапу (до хвилини) та кількість точок відновлення. Поля стану в =Azure= різні для різних
типів елементів (VM, база даних, файлова ~share~), тож будь-яке відсутнє — ~-~.

* Точки відновлення

З ~item~ замість огляду показуємо точки відновлення цього елемента в кожному сховищі, де він є (ім'я
VM може бути захищене в кількох сховищах одразу, тож ~name~ звужує до одного). Рядок точки:
~name~ — ідентифікатор точки, саме його приймає ~az backup restore~ (~--rp-name~); ~recoveryPointTime~ —
час (до секунди, ~UTC~); ~recoveryPointType~ — узгодженість (~CrashConsistent~, ~AppConsistent~,
~FileSystemConsistent~); рівень — ~recoveryPointTierDetails~ (~InstantRP~ — миттєва точка біля диска,
~HardenedRP~ — у сховищі; точка може бути в обох). Від новіших до старіших. Ім'я елемента порівнюється
без огляду на регістр із ~friendlyName~.

#+begin_src rust :noweb-ref Визначення
  fn point(entry: &serde_json::Value) -> String {
      let tiers: Vec<&str> = entry
          .pointer("/properties/recoveryPointTierDetails")
          .and_then(|items| items.as_array())
          .into_iter()
          .flatten()
          .map(|tier| tools::text(tier, "/type"))
          .collect();

      format!(
          "  {}  {}  {}  tier={}",
          tools::text(entry, "/name"),
          tools::text(entry, "/properties/recoveryPointTime").chars().take(19).collect::<String>(),
          tools::text(entry, "/properties/recoveryPointType"),
          if tiers.is_empty() { "-".to_string() } else { tiers.join(",") },
      )
  }

  async fn points(http: &reqwest::Client, one: &serde_json::Value, item: &str) -> Result<Option<String>, String> {
      let id = tools::text(one, "/id");
      let entries = client::list(http, &format!("{}/backupProtectedItems?{}", id, VERSION)).await?;
      let found: Vec<&serde_json::Value> = entries.iter().filter(|entry| tools::same(tools::text(entry, "/properties/friendlyName"), item)).collect();

      if found.is_empty() {
          return Ok(None);
      }

      let mut lines = Vec::new();

      for entry in found {
          let mut all = client::list(http, &format!("{}/recoveryPoints?{}", tools::text(entry, "/id"), VERSION)).await?;

          all.sort_by_key(|entry| std::cmp::Reverse(tools::text(entry, "/properties/recoveryPointTime").to_string()));
          lines.push(format!("{}  {}  points={}", tools::text(one, "/name"), tools::text(entry, "/properties/friendlyName"), all.len()));
          lines.extend(all.iter().map(point));
      }

      Ok(Some(lines.join("\n")))
  }

* Дія

Для кожного сховища: тип зберігання, політики, елементи й для кожного елемента кількість точок
відновлення (окремий запит на елемент, тож сховище з багатьма елементами відповідає повільніше). Фільтр
~name~ лишає одне сховище без огляду на регістр.

#+begin_src rust :noweb-ref Визначення
  async fn tree(http: &reqwest::Client, one: &serde_json::Value) -> Result<String, String> {
      let id = tools::text(one, "/id");
      let config = client::get(http, &format!("{}/backupstorageconfig/vaultstorageconfig?{}", id, VERSION)).await?;
      let full = client::get(http, &format!("{}?api-version=2024-04-01", id)).await?;
      let policies = client::list(http, &format!("{}/backupPolicies?{}", id, VERSION)).await?;
      let mut entries = client::list(http, &format!("{}/backupProtectedItems?{}", id, VERSION)).await?;
      let mut lines = vec![vault(one, &full, &config, entries.len())];

      for one in tools::sorted(&policies) {
          lines.push(policy(one, entries.iter().filter(|entry| tools::same(tools::text(entry, "/properties/policyName"), tools::text(one, "/name"))).count()));
      }

      entries.sort_by_key(|entry| tools::text(entry, "/properties/friendlyName").to_lowercase());

      for entry in &entries {
          let points = client::list(http, &format!("{}/recoveryPoints?{}", tools::text(entry, "/id"), VERSION)).await?.len();

          lines.push(item(entry, points));
      }

      Ok(lines.join("\n"))
  }
